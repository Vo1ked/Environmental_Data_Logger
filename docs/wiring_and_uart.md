# Підключення та перший запуск USB–UART

## Обладнання

ESP32-S3, DS1307 із батарейкою, BME280 із доступними CSB і SDO та SSD1306 128×64 (0x3C). Нижче наведені номери GPIO, а не порядкові номери контактів роз’єму.

## Датчики й екран

| ESP32-S3 | OLED SSD1306 | RTC DS1307 |
| --- | --- | --- |
| GPIO8 | SDA | SDA |
| GPIO9 | SCL | SCL |
| GND | GND | GND |
| 3V3 | VCC сумісного модуля OLED на 3,3 В | — |
| 5V/VBUS | — | VCC звичайного модуля DS1307 на 5 В |

Основне живлення DS1307 — 4,5–5,5 В; живлення конкретної плати залежить від її схеми. SDA/SCL з боку ESP повинні мати підтягування до **3,3 В**, а не 5 В. Перед підключенням спільної шини перевірити резистори підтягування RTC-модуля. За підтягування до 5 В потрібна зміна схеми або відповідне узгодження рівнів. Внутрішні підтягування I²C у прошивці вимкнені. Джерело параметрів: [DS1307 datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/DS1307.pdf).

Батарейку встановити з правильною полярністю; її тип має відповідати схемі резервного живлення та заряджання модуля. Вона підтримує відлік часу, але не замінює основного живлення для звичайної роботи I²C.

| ESP32-S3 | BME280, чотирипровідний SPI |
| --- | --- |
| 3V3 | VCC/VIN, якщо модуль допускає таке живлення |
| GND | GND |
| GPIO11 | SDA/SDI/MOSI |
| GPIO13 | SDO/MISO |
| GPIO12 | SCL/SCK |
| GPIO10 | CS/CSB |

Чотириконтактний модуль BME280 лише з I²C, без CSB/SDO, не підходить. Усі пристрої повинні мати спільну землю.

## Підключення USB–UART

Потрібен адаптер із логічними рівнями **3,3 В**.

1. Вимкнути живлення перед підключенням проводів.
2. Перевірити маркування мікросхеми та рівні TXD/RXD. Перемичка 3V3/5V іноді перемикає лише вихід VCC; вона не гарантує рівня TXD. За невідомої схеми перевірити документацію та напругу TXD у спокої відносно GND.
3. З’єднати контакти за таблицею:

   | USB–UART | ESP32-S3 | Напрямок |
   | --- | --- | --- |
   | TXD | GPIO18 | Адаптер передає → ESP приймає |
   | RXD | GPIO17 | ESP передає → адаптер приймає |
   | GND | GND | Спільна земля |

4. **VCC, 5V та 3V3 адаптера залишити непідключеними**, якщо ESP живиться від власного USB.
5. Підключити USB плати ESP для живлення/прошивання та USB адаптера до комп’ютера. Для команд використовувати COM-порт адаптера.
6. У Windows знайти порт у диспетчері пристроїв, у категорії COM і LPT. Назва та драйвер залежать від мікросхеми адаптера.
7. Відкрити порт у терміналі: **115200 бод, 8 бітів даних, без парності, 1 стоп-біт, без керування потоком**. Завершення рядка — LF або CRLF. За потреби увімкнути local echo.

GPIO17/18 використовуються окремим UART1 і не перетинаються з датчиками. Якщо вони зайняті на конкретній платі, змінити `EDL_UART_TX_GPIO` / `EDL_UART_RX_GPIO` у menuconfig та відповідні підключення.

## Пробудження та команди

Після запуску пристрій видає READY і залишає 30 секунд для введення. Для пробудження:

1. Надіслати `UUU` із переведенням рядка.
2. Дочекатися `READY`; за відсутності відповіді повторити рядок пробудження.
3. Надіслати `status` із переведенням рядка.

Не надсилати пробудження й важливу команду одним пакетом: перші символи можуть втратитися. Кожен вхідний фрагмент продовжує сеанс на 30 секунд. Під час сеансу ESP продовжує вимірювання та запис, але не входить у Light Sleep. Після паузи сон поновлюється.

Вбудований USB ESP може втрачати з’єднання під час Light Sleep, тому для команд використовується зовнішній адаптер. [Пояснення Espressif](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-guides/usb-serial-jtag-console.html#sleep-mode-considerations).

## Перший запуск

1. Зібрати й прошити проєкт разом із таблицею розділів. У menuconfig вибрати Custom partition table: `partitions.csv`; flash — 2 MB. Для переходу зі старої розмітки спочатку експортувати дані, після оновлення виконати `erase` та `log on`.
2. Підключитися до COM-порту адаптера, отримати READY та виконати `status`.
3. Установити актуальний UTC: `time set YYYY-MM-DDTHH:MM:SSZ`. Приклад синтаксису: `time set 2026-11-12T12:00:00Z`; ця дата не є поточною.
4. Перевірити місцевий час за `EDL_TIMEZONE`. `status` і `read` використовують формат `HH:MM:SS DD-MM-YYYY +N UTC` із фактичним зміщенням для дати запису. RTC має містити UTC; зміщення застосовується лише під час відображення.
5. Через 30 секунд у RAM з’явиться перший запис. Виконати `flush`, дочекатися `OK: flush`, потім виконати `read`. Приклад рядка: `0, 16:32:14 13-11-2026 +2 UTC: T = 23.7 C H = 51.6% P = 735 mmHg`. Підписи й одиниці додаються під час виведення; бінарний запис містить числові значення та CRC32.
6. Перед плановим вимкненням виконати `log off`, дочекатися відповіді, виконати `flush`, дочекатися OK і вимкнути живлення. За BUSY повторити команду після завершення поточної операції.

## Команди та діагностика

| Команда | Дія |
| --- | --- |
| `status` | Стан пристроїв, RAM/flash, режим, WDT і лічильник Light Sleep |
| `log off` / `log on` | Вимкнення / увімкнення накопичення |
| `flush` | Збереження накопичених записів без заповнення залишку сектора |
| `read` | Останні 16 збережених записів; RAM не виводиться |
| `read 0 100` | До 100 записів із нульового індексу; максимум 256 за запит |
| `erase` | Видалення архіву й RAM-буфера; після завершення залишається OFF |
| `help` | Коротка довідка |

Архів містить поточний день UTC і 30 попередніх. Під час зміни дня застарілий слот повторно використовується автоматично. `erase` призначена для повного очищення.

Якщо відповіді немає, перевірити COM-порт, спільну землю, перехресне з’єднання TX/RX, рівні 3,3 В, швидкість і LF/CRLF. BME280 ERROR вимагає перевірки SPI та типу датчика: BMP280 без вимірювання вологості не підходить. RTC ERROR означає недоступний або некоректний годинник. Помилка одного пристрою не повинна зупиняти доступні функції, проте фізично заблокована SDA/SCL може одночасно порушити роботу RTC та OLED.
